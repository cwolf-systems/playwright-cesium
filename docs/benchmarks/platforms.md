# Platforms

What each browser can do for CesiumJS on each platform, measured by `bench/platforms.mjs`
(`npm run bench:platforms`) on 2026-10-06 with CesiumJS 1.146 and Playwright 1.60 (Chromium 153,
Firefox 155, WebKit 26.6). "Cesium" is the demo scene with Cesium's default WebGL 2 context: the
median time from navigation until the scene has settled over three loads, each in a fresh browser
context as a test suite runs its tests, with the range in brackets. "Cesium, WebGL 1" asks for a
WebGL 1 context. The GitHub runners' tables come from one run of the probe workflow.

## What it means for a test suite

- **Compare within a table, not across runs.** Shared runners differ from one run to the next: the
  default Chromium on Linux x64 took 5.4 s in one run and 10.0 s in the next.
- **Chromium on CI renders in software everywhere.** GitHub's Linux and Windows runners have no
  GPU. In fresh contexts, launching with `--use-angle=swiftshader` settled the scene faster than
  the default on every runner: 3.6 s against 10.0 s on Linux x64, 4.6 s against 9.4 s on Linux
  ARM and 6.5 s against 11.1 s on Windows. Reloading one page instead, its loads got slower each
  time (2.2 s, then 6.7 s and 7.5 s on Linux x64), so measure it in the suite it is meant for.
- **Playwright's default headless Chromium is software-rendered even where there is a GPU.** It runs
  a separate headless-shell binary that uses SwiftShader; full Chromium (`channel: 'chromium'`)
  uses the GPU on macOS and settled about three times as fast there (2.8 s against 8.1 s on the
  runner, 1.1 s against 3.6 s locally).
- **Firefox needs `webgl.force-enabled` on Windows runners.** By default it offers WebGL 1 but no
  WebGL 2 there, and CesiumJS refuses to start rather than fall back; with the preference it gets
  WebGL 2 on Direct3D's software driver and settles in about 5 s. Firefox has no WebGL at all on
  GitHub's Linux runners (x64 and ARM), preference or not, and takes about 40 s on macOS runners.
- **WebKit renders on Linux and macOS,** settling in 1.3–5.1 s on CI, but cannot run CesiumJS 1.146
  on Windows: Playwright's Windows build has no `OffscreenCanvas`, which CesiumJS references
  without checking that it exists. WebKit reports its renderer as "Apple GPU" on every platform,
  and Firefox reports "Apple M1, or similar" on macOS: neither names the real device.
- **WebGL 1 does not help.** Since CesiumJS 1.139, labels and billboards fail to compile under WebGL
  1 in every browser measured (a `flat` qualifier the WebGL 1 shader translation does not
  remove). On Linux, WebKit fails under WebGL 1 with a different error, from ground-clamped
  polygons.
